## 二、 原型设计准则（蓝白执法风格）

基于 **“深蓝（#0a2f6c） + 亮蓝（#2563eb） + 白（#ffffff）”** 的主色盘，结合执法场景的高压、快速、精准特点，制定以下设计准则：

### 1. 全局色彩体系（执法高对比）





| 色彩角色     | 色值                                                         | 应用场景                             | 设计意图                         |
| :----------- | :----------------------------------------------------------- | :----------------------------------- | :------------------------------- |
| **执法深蓝** | `#0a2f6c`                                                    | 顶部导航栏、底部状态栏、主要标题背景 | 象征权威、沉稳，降低视觉浮躁     |
| **行动亮蓝** | `#2563eb`                                                    | 主按钮、进度条、选中状态、可交互控件 | 代表“可执行”，高亮指引操作       |
| **纯净白**   | `#ffffff`                                                    | 卡片背景、内容区底色                 | 最大化内容清晰度，减少干扰       |
| **警示橙**   | `#ea580c`                                                    | **“优先”按钮**、紧急标记（⭐）        | 与蓝白形成强烈反差，瞬间吸引注意 |
| **状态语义** | `#22c55e`（成功/在线） `#ef4444`（故障/危险） `#f59e0b`（暂停/警告） | 状态徽章、进度条颜色                 | 符合直觉（绿通、红断、黄缓）     |

### 2. 触屏与桌面适配准则





| 维度         | 采集站桌面端（触屏）                                         | 平台/单机版Web端（鼠标）           |
| :----------- | :----------------------------------------------------------- | :--------------------------------- |
| **导航布局** | **顶部Tab导航**（5个以内），最大化内容竖向空间               | **左侧菜单**（可折叠）+ 右侧内容区 |
| **点击区域** | 所有交互热区 **≥ 44x44 pt**，按钮间距 ≥ 8px                  | 标准 32x32 pt，允许更紧凑的排版    |
| **交互反馈** | 点按**缩放动画**（scale 0.97），危险操作触发触觉震动（模拟） | 悬停变色 + 点击水波纹              |
| **布局密度** | 卡片网格响应式（默认5列，自适应3~4列），信息密度适中         | 列表/表格为主，支持批量勾选操作    |

### 3. 核心组件交互规范

- **合并主操作按钮（桌面端特有）**：
  - 根据状态动态切换文字：`开始` → `暂停` → `恢复` → `已完成`（禁用）。
  - 仅保留 **主控按钮**（蓝/橙）+ **取消**（红）+ **优先**（橙），减少认知负担。
- **数据卡片设计**：
  - 顶部 **状态徽章**（采集中/已暂停/故障等）常驻，颜色语义化。
  - 进度条加粗至 **12px**，便于远距离查看。
  - 记录仪信息层级：`端口号（最大）> 设备ID > 协议标签 > 电量`。
- **日志脱敏展示**：
  - 姓名/身份证号自动替换为 `张**` 或 `***************`。
  - 界面显式标注 `🔒 已脱敏`，符合合规审查要求。

### 4. 布局骨架规范





| 页面区域       | 采集站桌面端（15寸触屏）                                     | Web管理后台                                        |
| :------------- | :----------------------------------------------------------- | :------------------------------------------------- |
| **顶部导航**   | 高度 **64px**，深蓝底，Logo + 系统名 + 5个一级菜单 + 授权状态 | 高度 **56px**，白底，Logo + 全局搜索/通知/用户头像 |
| **二级导航**   | （仅“数据管理/系统管理”出现）高度 44px，胶囊式Tab            | 位于左侧菜单点击后展开的子项                       |
| **主内容区**   | 全屏滚动，卡片网格自适应                                     | 固定宽度流式布局，最大宽度 1440px 居中             |
| **底部状态栏** | 高度 **56px**，深蓝底，固化显示：IP/网络/磁盘/CPU/心跳/在线/今日/待上传 | 无底部状态栏（资源监控独立在仪表盘）               |

### 5. 反馈与动效准则

- **操作反馈**：所有按钮点击必须在 **150ms** 内给出视觉反馈（颜色变化或缩放），减少执法人员的等待焦虑。
- **数据刷新**：仪表盘数据采用 **静默轮询**（间隔5秒），无刷新按钮（已被移除），避免不必要的点击。
- **弹窗策略**：
  - 桌面端：优先使用**底部面板（Bottom Sheet）**展示详情（如点击卡片查看文件列表），不打断当前采集流程。
  - Web端：使用**模态对话框（Modal）**或**右侧抽屉（Drawer）**用于编辑配置。

### 6. 安全与合规可视化

- **国密标识**：在登录页及“关于”页面显眼位置显示 `🇨🇳 支持国密 SM2/SM3/SM4`。
- **加密锁标识**：文件列表中的加密文件统一添加 `🔒` 前缀。
- **签名状态**：关键操作（如违规标注、配置下发）完成后，在详情页显示 `✅ 已数字签名` 及时间戳，增强证据链可信度。
